# iVPN

Здесь публикуются только установочные файлы приложения iVPN для Android. Исходного кода в этом репозитории нет.

## Скачать

Последняя версия — на странице **[Releases](https://github.com/ivpn-plus/ivpn/releases/latest)**.

| Платформа | Где скачать | Минимальная версия системы |
|---|---|---|
| Android | `iVPN-<версия>.apk` в Releases | Android 7.0 и новее; процессор ARM (arm64-v8a или armeabi-v7a) |
| iPhone и iPad | App Store | iOS / iPadOS 16.0 и новее (Live Activity — с iOS 16.2, кнопка «Отключить» в ней — с iOS 17) |
| macOS | скоро в App Store | macOS 13 Ventura и новее |
| Windows | скоро | — |

## Установка

**Android.** Скачайте `iVPN-<версия>.apk` и откройте его. Если Android попросит, разрешите установку из этого источника. При первом подключении система спросит разрешение на VPN — нажмите «ОК». Дальше приложение само предложит обновиться, когда выйдет новая версия.

**iPhone и iPad.** Через App Store.
