# iVPN

Здесь публикуются только установочные файлы приложения iVPN. Исходного кода в этом репозитории нет.

## Скачать

Последняя версия — на странице **[Releases](https://github.com/ivpn-plus/ivpn/releases/latest)**.

| Платформа | Файл | Минимальная версия системы |
|---|---|---|
| Android | `iVPN-<версия>.apk` | Android 7.0 и новее; процессор ARM (arm64-v8a или armeabi-v7a) |
| macOS | `iVPN-<версия>-macOS.dmg` | macOS 11 Big Sur и новее на Apple Silicon; macOS 10.15 Catalina и новее на Intel |
| iPhone и iPad | App Store | iOS / iPadOS 16.0 и новее (Live Activity — с iOS 16.2, кнопка «Отключить» в ней — с iOS 17) |
| Windows | скоро | — |

Файлы `iVPN-<версия>-macOS-arm64.zip` и `-x64.zip` в релизе нужны для автообновления приложения на Mac — скачивать их вручную не нужно.

## Установка

**Android.** Скачайте `iVPN-<версия>.apk` и откройте его. Если Android попросит, разрешите установку из этого источника. При первом подключении система спросит разрешение на VPN — нажмите «ОК». Дальше приложение само предложит обновиться, когда выйдет новая версия.

**macOS.** Откройте `iVPN-<версия>-macOS.dmg` и перетащите iVPN в «Программы». Приложение подписано и проверено Apple. При подключении macOS попросит пароль администратора — он нужен, чтобы создать VPN-интерфейс.

**iPhone и iPad.** Через App Store.
