# iVPN

Здесь публикуются установочные файлы приложения iVPN для **Android** и **Windows**. Исходного кода в этом репозитории нет.

Сайт приложения, документация и ответы на частые вопросы — **[app.iapps.sbs](https://app.iapps.sbs)**.

## Скачать

| Платформа | Где скачать | Минимальная версия системы |
|---|---|---|
| Android | `iVPN-<версия>.apk` в **[Releases](https://github.com/ivpn-plus/ivpn/releases/latest)** | Android 7.0 и новее; процессор ARM (arm64-v8a или armeabi-v7a) |
| Windows | `iVPN-Setup-<версия>.exe` в **[Releases](https://github.com/ivpn-plus/ivpn/releases/latest)** | Windows 10 и 11, 64-бит |
| iPhone и iPad | **[TestFlight](https://testflight.apple.com/join/4CWpp5Pg)** | iOS / iPadOS 15.0 и новее (виджеты — с iOS 16.1, Live Activity — с iOS 16.2, переключатель в Пункте управления — с iOS 18) |
| Mac | **[TestFlight](https://testflight.apple.com/join/4CWpp5Pg)** | macOS 13 и новее, Apple Silicon и Intel |

## Установка

**Android.** Скачайте `iVPN-<версия>.apk` и откройте его. Если Android попросит, разрешите установку из этого источника. При первом подключении система спросит разрешение на VPN — нажмите «ОК». Дальше приложение само предложит обновиться, когда выйдет новая версия.

**Windows.** Скачайте `iVPN-Setup-<версия>.exe` и запустите. Установщик без цифровой подписи: если Windows покажет «Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае». Новые версии приложение предложит само.

**iPhone, iPad и Mac.** Через TestFlight: установите приложение TestFlight из App Store и откройте [приглашение](https://testflight.apple.com/join/4CWpp5Pg). Новые сборки TestFlight предложит сам.

Подробная инструкция — в [документации](https://app.iapps.sbs/docs/).
