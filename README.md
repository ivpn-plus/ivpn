# iVPN

Здесь публикуются только установочные файлы приложения iVPN. Исходного кода в этом репозитории нет.

## Скачать

Последняя версия — на странице **[Releases](https://github.com/ivpn-plus/ivpn/releases/latest)**.

| Платформа | Файл |
|---|---|
| Android | `iVPN-<версия>.apk` |
| macOS | скоро |
| Windows | скоро |

iPhone и iPad — через App Store.

## Установка на Android

1. Скачайте `iVPN-<версия>.apk` из последнего релиза.
2. Откройте файл и разрешите установку из этого источника, если Android попросит.
3. Приложение само предложит обновиться, когда выйдет новая версия.
